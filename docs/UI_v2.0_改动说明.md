# UI v2.0 改动说明（app.py 界面重构）

**基线**：v1.6（统一接线版）→ **目标**：v2.0（界面重构版）
**原则**：只动展示层。`modules/`、`utils/vector_store.py`、`knowledge/` **零改动**；
新增/替换仅 3 个文件 + 1 个目录。

## 一、交付文件

| 文件 | 状态 | 说明 |
|---|---|---|
| `app.py` | 替换 | 四标签页重构，约 890 行（原 ~600 行） |
| `utils/ui_style.py` | 新增 | 全局视觉系统：CSS 注入 / 语义徽章 / 空状态组件 |
| `.streamlit/config.toml` | 新增 | 主题：金融蓝 #1F4E79 + 浅灰底 + 白卡片 |
| `docs/UI_v2.0_改动说明.md` | 新增 | 本文档 |

部署方式：直接覆盖仓库同名文件即可，无新依赖（requirements.txt 不变）。

## 二、修复的两个 P0 交互缺陷

**P0-1 结果消失 bug（演示事故高发区）**
- v1.6：诊断结果、双轨、产品匹配、差距分析、报告下载全部渲染在 `if st.button(...)` 块内，
  任何 rerun（改输入、存 Key、在页面底部 RAG 提问）都会清空整页结果。
- v2.0：诊断在表单提交时计算并写入 `session_state`（`diagnosis_result` / `full_metrics` /
  `llm_text`），**渲染全部在按钮块外、从 session_state 读取**。切 Tab、追问 RAG 不再丢结果。

**P0-2 逐键全量 rerun**
- v1.6：15+ 录入控件各自触发整页重跑；224 页年报文本常驻 session_state，1GB 云端有卡顿/OOM 风险。
- v2.0：录入区包进 `st.form` + `st.form_submit_button`，一次提交一次 rerun；
  问答区 `st.fragment` 独立刷新；文件解析按文件签名去重（同一文件不重复解析）；
  产品库 `st.cache_data`、RAG 索引 `st.cache_resource`。

## 三、信息架构（单页 → 四标签页）

| Tab | 内容 |
|---|---|
| ① 数据录入 | 上传区 / AI 提取 / 会计校验 / 原始数据 expander / 指标确认（data_editor）/ 补充信息表单 / 空状态 hero / **手动录入路径（新增）** |
| ② 诊断报告 | 总览条（评分徽章 + ML 违约概率 + 双轨结论）/ 8 维配色条形图 + 徽章网格 / SHAP 归因（正负配色）/ 风险与建议两列 / PDF 生成与下载 |
| ③ 产品匹配与差距 | 匹配表 / AI 推荐（按钮触发）/ 行动优先级表 / 逐产品差距 expander / 完整产品库（折叠） |
| ④ 政策问答 | 检索问答（fragment）/ 参考清单（条款摘编标注）/ 检索截至日期 + 产品库指纹 |

关键结构调整：
- 产品库全表：常驻底部 → Tab3 底部 expander 折叠。
- 指标修正墙（动态 N 个 text_input）→ `st.data_editor` 单表（指标｜数值｜单位｜来源页，数值可编辑、其余只读）。
- 补充信息 5 组平铺 → 基础组（经营/行业/利率/客户集中度 + 账龄）+「高级选项」expander（信用评级、增长率、行业周期信号）。
- **新增纯手动录入路径**：勾选"手动录入指标"即生成 11 个 `diagnose()` 消费的原始键模板（总资产/总负债/营业收入/营业成本/净利润/流动负债/经营活动现金流净额/利息费用/应收账款/存货/流动比率），无文件也能演示全流程。

## 四、视觉系统

- `config.toml`：primaryColor `#1F4E79`、页面底 `#F7F8FA`、卡片 `#FFFFFF`、正文 `#374151`。
- `ui_style.py`：`.fd-badge` 语义徽章（绿/黄/红/蓝，红黄绿阈值与规则卡一致 7/4）、hero 空状态、empty_state 引导组件。
- 8 维评分：2×4 metric + 文字灯 → **Altair 横向条形图（按红黄绿阈值着色）** + 徽章网格。
- SHAP 归因：默认 bar_chart → **Altair 正负配色条形图**（红=推高违约、绿=拉低违约），两图均有 `st.bar_chart` 兜底。
- emoji 纪律：15+ 个标题 emoji → 仅保留状态标注（✅⚠️）与 page_icon。
- 侧边栏：不再回显 API Key 片段（只显示"已配置/未配置"）；移除单选项模型下拉（改为常量 `MODEL_NAME`）；新增「使用说明」expander。

## 五、行为变更（有意为之，请知悉）

1. **AI 产品推荐**由"匹配后自动调用 LLM"改为**按钮触发**（`生成 AI 产品推荐说明`），
   避免每次 rerun 消耗 API 额度；无匹配时的改善建议同理。推荐文本会随 PDF 落库（与 v1.6 一致）。
2. **LLM 诊断文本**在提交诊断时生成一次并缓存（`session_state.llm_text`），Tab2 渲染不再重复调用。
3. 指标编辑器以 `metrics_rev` 作为 key 后缀：AI 提取或换文件后编辑器自动重建显示新值，
   替代 v1.6 逐个 `pop(metric_{k})` 的清缓存写法。
4. 双轨对照结论用 `st.info` 卡片常驻总览条（v1.6 为普通 markdown）。
